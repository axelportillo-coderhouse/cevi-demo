# Cevi IA — Demo

Demo estática de **Cevi IA**, el motor de matching cultural de CVs de Coderhouse.

🔗 **https://axelportillo-coderhouse.github.io/cevi-demo/**

Apretá **"Crear mi CV"** para ver el flujo: el CV se adapta al mercado, se renderiza en
7 estilos y se exporta a PDF — todo en el navegador, con datos de ejemplo.

> Sitio estático (sin backend). El código del producto vive en un repositorio privado.
